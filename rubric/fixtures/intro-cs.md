# Intro CS Project Rubric

- Testing (30%): at least 20% of analyzed files should be tests.
- Documentation — 20 pts: comments explain the program and how to run it.
- Code style (20%): no file over 300 lines.
- Project layout (10%): must contain a tests/ folder.
- Version control (10%): at least 10 commits.
- Required language (10%): written in Python.
- Demo clarity: explain one design decision to the class.
