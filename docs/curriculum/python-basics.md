# Python 基础预设课程

在教师建课页选择“Python 预设课程”，点击“载入这节课”，按需要调整任务和时间，再发布。选择下拉框只预览，不覆盖草稿；载入会替换尚未发布的草稿。每课 3 步、建议 30 分钟，可暂停、延长、重试。

| 课程 | 三步任务 | 学生文件 |
|---|---|---|
| 01 · 输出与变量 | 让程序开口 → 把信息放进变量 → 升级介绍卡 | python/01_hello.py |
| 02 · 数字、输入与类型转换 | 读入一个数字 → 拆成分钟与秒 → 检查边界 | python/02_numbers.py |
| 03 · 字符串整理器 | 去掉首尾空白 → 统一和替换 → 做一个安全预览 | python/03_strings.py |
| 04 · 条件判断 | 判断是否通过 → 加入多个等级 → 拒绝范围外的分数 | python/04_conditions.py |
| 05 · for 与 range | 重复而不复制 → 累加训练得分 → 只累计偶数 | python/05_for.py |
| 06 · while 与循环终止 | 可终止的倒计时 → 重复读取直到停止 → 给程序加护栏 | python/06_while.py |
| 07 · 列表与序列 | 建立与修改背包 → 逐个展示物品 → 空背包也能用 | python/07_lists.py |
| 08 · 函数与返回值 | 传入参数，拿回结果 → 封装列表求和 → 用断言防止改坏 | python/08_functions.py |
| 09 · dict：班级物资仓库 | 从列表升级为键值对 → 安全查询与入库 → 生成报告并自测 | python/09_dict.py |

教师可下载每课的 Python 3 起始文件，并查看前置知识、教学节奏、边界案例与复核建议。学生在自己的编辑器运行，push 到 GitHub 后提交；自测与改进记录保存在仓库根目录 README.md。

预设使用静态文件/源码片段检查，检查通过不等于功能正确，也不执行任意学生代码。教师应根据每步给出的案例检查实际输出，并接受正确的等价实现；可以修改文本检查或配置自己的 GitHub CI 检查。
