# Four-language interface and provider fallback

English (`en`), Simplified Chinese (`zh`), Spanish (`es`) and French (`fr`) use a bundled catalog. Gameplay never waits for a translation request. The global selector saves a personal browser preference. In classrooms the server's room language overrides it; only the owning teacher's screen session can change the room language. Reconnects and server persistence retain that choice. Leaving the classroom restores the personal preference.

Official Python lessons, starter-file comments and teacher guides use the same catalog. Template localization changes only fields still matching an official template. Teacher-authored instructions, edited titles, GitHub paths, literal evidence checks and program-output examples remain intact. Language changes update the existing editor without discarding unsubmitted checks.

Generate public application text with `npx tsx tools/generate-i18n.ts`. Gemini is called through AGY (`gemini-3.8-flash-high`); failed batches can fall back to the configured DeepSeek API. Both paths must pass the same ID, completeness and placeholder validation. `shared/i18n/gemini-translations.json` retains provider provenance, and `generation.json` reports provider counts. No student submissions or private repository source are sent by this tool.

Run `npx tsx tools/audit-i18n.ts` to check catalog coverage, placeholder parity and all 36 Python starter files, including identical executable syntax trees across languages. Inspect `shared/i18n/review.json` for remaining foreign-language text or changed code literals. Browser checks: `npx tsx tools/i18n-smoke.ts` and `npx tsx tools/classroom-smoke.ts`.

## Runtime design fallback

Server-side appearance generation tries Gemini first. Authentication, billing and rate-limit failures immediately switch to DeepSeek and suppress further Gemini requests for two minutes. Other Gemini failures retain the existing lite-model retry before DeepSeek. Both providers use the same design validation and cache; if both fail, deterministic artwork keeps the game available. Private or credentialed analyses bypass both providers.

Configuration is read from the process environment, the project `.env`, then the parent `.env`. Use `DEEPSEEK_API_KEY` and optionally `DEEPSEEK_MODEL` (default `deepseek-flash`). Keys are sent in headers and never included in browser assets, URLs, generated catalogs or telemetry.

DeepSeek requests follow its [Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/), with JSON output, non-thinking mode and bounded output/time limits. Truncated completions, invalid JSON and unusable design objects do not enter the cache.
