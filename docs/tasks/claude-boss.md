# claude-boss: client/render/boss/ + client/render/arena/
You own those two dirs. Implement drawBoss, bossPortrait, drawArenaBackground, drawBullets, drawHazards, drawMinions, drawEvents, drawPostFx (BRIEF interface). Visual maxxing — this is the money shot.
- Boss: separate generator & palette from players. Weird, eldritch, asymmetric code-monster ~96–160 px, assembled from kit (limbs -> body lobes/arms sized by component, weakPoint limbs pulse red with "knot" texture, heart = glowing core with code scrolling inside), tentacles (bezier pixel chains swaying), many eyes (blink independently, track target player), teeth/maws made of brackets `}{`, scars. Broken limbs shown as sparking stumps with error glyphs. Phase visuals: phase 2 enraged red tint + steam, phase 3 exposed heart + glitch. Casting: wind-up pose, charge-up glow toward casting.target. Limb positions: the sim owns hitboxes; until a contract exists, place limbs deterministically from seed around (b.x,b.y) and document your layout function in docs/progress so sim can match (put it in a pure function `bossLayout(kit)` exported from client/render/boss/layout.ts with no DOM — the coordinator may move it to shared/).
- Arena per theme (terminal/kernel/web/notebook/enterprise/legacy): tiled floor 30x18 with walls, props, ambient animation (blinking LEDs, data flowing along traces, flickering monitors, falling green glyphs on the terminal theme), floor engravings of code, light pools. Pre-render static layers once per (theme, seed).
- Bullets as glyph projectiles with glow (additive), per weapon/attack kind; hazards with marching-ants telegraph + red stack-trace text using attack name; lasers with charge then beam; slam rings; cascade lightning arcs. Minions = little bug sprites (literal bugs).
- drawEvents: damage numbers ("-12", crits "-40 CRIT", combos "x3 COMBO"), glitch flashes, glyph shrapnel on limb break, phase-change full-screen glitch, victory BSOD/segfault burst. Keep own particle pool.
- drawPostFx: scanlines, vignette, chromatic aberration pulse on shake.
- Dev gallery `client/render/boss/gallery.html` showing bosses from several synthetic kits on each arena theme with live animation + fake bullets/hazards. Screenshot with Playwright/headless chromium and LOOK at it; iterate until it's stunning.
