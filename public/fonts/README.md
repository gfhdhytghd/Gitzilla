GNU Unifont 18.0.01, downloaded from https://unifoundry.com/pub/unifont/unifont-18.0.01/font-builds/unifont-18.0.01.otf .

The WOFF2 file is a lossless web-font conversion of the complete upstream OTF (no glyph subsetting), made with fontTools. It covers the Basic Multilingual Plane, including teacher-authored Chinese beyond the bundled translations. The supplied Unifont-LICENSE.txt contains the upstream dual license; the compiled font may be used under SIL OFL 1.1.
